# 07 Trainable measurement angles

## Goal

Explore trainable measurement angles with an explicit representation contract.

## Theory

PhotoGraphiQ Parameter expressions identify angles while separate metadata records trainability and frozen values.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
m = pqml.MuTA(1)
m.freeze('alpha.w0.c3', 0)
assert m.n_parameters == 3
print(list(m.trainable_parameters()))
m.unfreeze('alpha.w0.c3')
assert m.n_parameters == 4
```
