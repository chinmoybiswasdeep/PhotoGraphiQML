# 16 Finite-difference validation

## Goal

Explore finite-difference validation with an explicit representation contract.

## Theory

Central differences have second-order truncation error for smooth objectives until floating-point cancellation dominates.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
from photographiqml.training import finite_difference
p = np.array([0.3,-0.2])
g = finite_difference(lambda x: np.sum(x**2),p)
assert np.allclose(g,2*p,atol=1e-8)
print(g.round(6))
```
