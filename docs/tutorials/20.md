# 20 MentPy cross-validation

## Goal

Explore mentpy cross-validation with an explicit representation contract.

## Theory

The optional pinned reference compares semantic topology and logical density matrices. It is not a reference for arbitrary CV amplitudes.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
import importlib.util
if importlib.util.find_spec('mentpy'):
    from photographiqml.validation import compare_mentpy
    m = pqml.MuTA(2,one_column=True)
    error = compare_mentpy(m,[1,0,0,0],m.initialize(2))
    assert error<1e-10
    print('Logical density agreement:',error<1e-10)
else:
    print('Optional MentPy reference not installed')
```
