# 23 Bias engineering

## Goal

Explore bias engineering with an explicit representation contract.

## Theory

The paper's inductive bias is imposed through graph connectivity and angle restrictions. Explicitly freezing an angle changes the variational family.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
m = pqml.MuTA(2,one_column=True,connections=())
assert m.graph.number_of_edges()==8
m.freeze('alpha.w0.c1',0)
assert m.n_parameters==7
m.unfreeze('alpha.w0.c1')
assert m.n_parameters==8
print('Topology and angle constraints are explicit')
```
