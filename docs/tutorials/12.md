# 12 Classical classification

## Goal

Explore classical classification with an explicit representation contract.

## Theory

A trainable MuTA followed by first-wire Z expectation and a logistic head yields probabilities for labels zero and one.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
X = [[0],[0.1],[3.0],[3.14]]
y = [1,1,0,0]
c = pqml.MuTAClassifier(pqml.MuTA(1),trainer=pqml.Trainer(epochs=60))
c.fit(X,y)
assert c.score(X,y) == 1
print(c.predict([[0.05],[3.1]]))
```
