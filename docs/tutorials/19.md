# 19 GKP logical MuTA

## Goal

Explore gkp logical muta with an explicit representation contract.

## Theory

The bridge distinguishes an ideal logical target from a finite-energy resource. Full GKP MuTA must fail explicitly until a measurement/injection instrument and decoder are available.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
m = pqml.MuTA(1,representation='gkp')
r = pqml.GKPBridge().logical_target(m,[1,0])
assert r.representation == 'logical'
try:
    m.run([1,0])
except NotImplementedError:
    print('Physical GKP MuTA is unsupported; ideal target remains logical')
else:
    raise AssertionError('Unexpected physical execution')
```
