# 03 First MuTA model

## Goal

Explore first muta model with an explicit representation contract.

## Theory

The public model exposes geometry, parameters and ideal output states separately. Wire zero is the most significant tensor factor.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
m = pqml.MuTA(2, one_column=True)
assert m.n_parameters == 8
print(m.summary())
```
