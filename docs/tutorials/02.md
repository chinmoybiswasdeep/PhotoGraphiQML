# 02 MuTA from the paper

## Goal

Explore muta from the paper with an explicit representation contract.

## Theory

Table I obtains IsingXX(-phi) from the base-center measurement. On |00>, phi=pi/2 creates a maximally entangled logical state.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
m = pqml.MuTA(2, one_column=True)
r = m.run([1, 0, 0, 0], {'alpha.w1.c1': np.pi/2})
assert np.allclose(r.probabilities, [0.5, 0, 0, 0.5])
print(r.probabilities.round(6))
```
