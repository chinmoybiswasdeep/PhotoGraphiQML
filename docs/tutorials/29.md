# 29 CV-native MuTA

## Goal

Explore cv-native muta with an explicit representation contract.

## Theory

A derived CV teleportation step has T(k)=[[-k,-1],[1,0]] with k=cot(theta). Four zero-shear steps are ideal identity, a potential composable cell ingredient.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
from photographiq.gaussian import teleportation_matrix
T = teleportation_matrix(0)
assert np.allclose(np.linalg.matrix_power(T,4),np.eye(2))
print('CV cell ingredient verified; CVMuTA is a proposal')
```
