# 01 What is MB-QML?

## Goal

Explore what is mb-qml? with an explicit representation contract.

## Theory

Measurement angles parameterize a logical map. An all-X four-measurement wire implements identity after Pauli correction.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
m = pqml.MuTA(1)
r = m.run([1, 0])
assert np.allclose(r.probabilities, [1, 0])
print(r.probabilities.round(6))
```
