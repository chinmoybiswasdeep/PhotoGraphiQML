# 15 Training with Adam

## Goal

Explore training with adam with an explicit representation contract.

## Theory

Adam uses bias-corrected first and second gradient moments. Each fit resets optimizer state; initial parameters are explicit.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
p,h = pqml.Trainer(epochs=180).fit(lambda p: np.sum((p-0.3)**2),[1,-1])
assert np.linalg.norm(p-0.3) < 0.001
print(p.round(4))
```
