# 25 Model serialization

## Goal

Explore model serialization with an explicit representation contract.

## Theory

JSON retains topology, stored values and frozen metadata without executing expressions or loading pickle objects.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
import tempfile
from pathlib import Path
m = pqml.MuTA(1)
m.freeze('alpha.w0.c1',0.3)
with tempfile.TemporaryDirectory() as d:
    p = Path(d)/'model.json'
    m.save(p)
    restored = pqml.MuTA.load(p)
    assert np.allclose(m.unitary(),restored.unitary())
print('Logical model round trip verified')
```
