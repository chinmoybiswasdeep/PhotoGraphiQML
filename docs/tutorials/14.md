# 14 MuTA quantum kernel

## Goal

Explore muta quantum kernel with an explicit representation contract.

## Theory

The kernel is squared feature-state overlap. Its Gram matrix is PSD because it is an inner product between pure-state density operators.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
k = pqml.MuTAKernel()
X = [[0,0],[1,0],[0,1]]
d = k.diagnostics(X)
assert d['minimum_eigenvalue'] > -1e-10
print(k.gram_matrix(X).round(4))
```
