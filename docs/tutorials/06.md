# 06 Multi-layer MuTA

## Goal

Explore multi-layer muta with an explicit representation contract.

## Theory

Composition identifies output sites with subsequent inputs, so each paper layer adds four sites per wire.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
m = pqml.MuTA(2, 2, one_column=True)
assert len(m.graph) == 18
assert m.output_nodes == ((0,8), (1,8))
print(m.output_nodes)
```
