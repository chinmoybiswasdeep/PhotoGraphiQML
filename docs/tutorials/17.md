# 17 Autodiff training

## Goal

Explore autodiff training with an explicit representation contract.

## Theory

The trainer accepts a supplied derivative callable. This example uses an analytical derivative to illustrate that interface; no autodiff backend is claimed.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
p,h = pqml.Trainer('lbfgs',epochs=20).fit(lambda x: np.sum(x*x), [1,2],gradient=lambda x: 2*x)
assert np.linalg.norm(p)<1e-8
print(p.round(6))
```
