# 05 Multi-wire MuTA

## Goal

Explore multi-wire muta with an explicit representation contract.

## Theory

A full layer rotates the choice of tip through the wires under MentPy's API convention. Connections within each paper layer share one tip.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
m = pqml.MuTA(3, 1)
assert m.paper_depth == 3
assert len(m.graph) == 39
print(m.summary())
```
