# 10 Gate learning

## Goal

Explore gate learning with an explicit representation contract.

## Theory

Average pure-state infidelity is the paper's supervised objective. The example fits a one-qubit X rotation on independently sampled states.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
from photographiqml.models import haar_states, infidelity
from scipy.linalg import expm
from photographiqml.logical import X
m = pqml.MuTA(1)
s = haar_states(1,7,42)
t = s @ expm(0.4j*X).T
def loss(p):
    return infidelity(m.run_batch(s,p),t)
p,h = pqml.Trainer(epochs=100).fit(loss, np.zeros(4))
assert h.losses[-1] < 1e-4
print(round(h.losses[-1],6))
```
