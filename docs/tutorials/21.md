# 21 Expressivity vs depth

## Goal

Explore expressivity vs depth with an explicit representation contract.

## Theory

All-X identity insertion proves weak inclusion when another logical layer is appended. It does not promise strictly larger families at every depth.

## Code

Run from the installed repository environment.

```python
import numpy as np
import photographiqml as pqml
a,b = pqml.MuTA(2,1),pqml.MuTA(2,2)
p = a.initialize(3)
assert np.allclose(a.unitary(p),b.unitary(p))
print('Identity extension verified')
```
