# Community conduct

Treat contributors respectfully. Debate scientific claims with evidence,
acknowledge uncertainty and give credit. Harassment, discriminatory language,
personal threats and publishing others' private information are unacceptable.

Maintainers may remove abusive content or restrict participation. Report
conduct concerns privately to a repository maintainer through an available
GitHub contact; avoid posting personal details publicly. Enforcement should be
proportionate and allow a good-faith explanation or correction.
